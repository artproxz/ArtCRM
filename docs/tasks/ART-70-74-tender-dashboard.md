# ART-70…ART-74 — Стабилизация тендерного дашборда

Связанные задачи Linear:
- ART-70 — unread-счётчики и read-all по вкладкам
- ART-71 — большие списки позиций без «Показать ещё 10»
- ART-72 — реальный этап торгов TenderPro
- ART-73 — единая семантическая цветовая палитра
- ART-74 — регрессия и PR

## Основные требования

### Unread
- основное число вкладки = total карточек;
- красный badge = unread карточек текущей вкладки;
- ручной unread увеличивает badge на 1;
- read уменьшает badge на 1;
- read-all работает только для выбранной вкладки;
- значения берутся из backend stats и не откатываются после refresh;
- исторические rejected-карточки без read-state не должны давать ложный `99+`;
- unread карточек и unread уведомлений колокольчика — разные механизмы.

### Позиции
- убрать «Показать ещё 10» и «Скрыть 10»;
- все канонические позиции доступны сразу внутри ограниченной по высоте таблицы;
- sticky header и внутренний vertical scroll;
- `Позиции (N шт.)` считается после dedup.

### Этап торгов
- извлекать фактический этап из TenderPro API/detail/raw/page data;
- ID 1216082 должен отображаться как `Этап 2/2`;
- не подставлять `Этап №1` по умолчанию;
- если данных нет, показывать `Этап не указан`.

### Цвета
- использовать единые semantic CSS tokens: success, review, warning, danger, info, neutral;
- одинаковые состояния используют одинаковые фон, рамку и тёмный текст.

## Ограничения
